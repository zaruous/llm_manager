## 운영 규칙

- 새 작업 주제가 생기면 GitHub Project에 항목을 먼저 추가하고, 상세 계획이 필요할 때 이 파일에 주제 인덱스를 추가한다.
- 주제 인덱스 파일은 배경, 목표 구조, 단계별 세부 문서 링크만 유지한다.
- 구현 단위, 수정 대상 파일, 완료 기준은 세부 TODO 파일에 작성한다.
- 현재 진행 상태와 상태 변경 이력은 GitHub Project에서만 관리한다.
- 이 파일에는 작업 항목과 상세 계획 문서 링크만 유지한다.
